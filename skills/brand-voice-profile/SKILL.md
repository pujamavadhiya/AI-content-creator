D. Voice and Credibility Skills
D1. Brand Voice Profile
name: brand-voice-profile
description: Capture and apply a brand's tone, vocabulary, and style rules. Use when a user wants content to match their brand, supplies sample posts, or asks to set up or edit their voice.
Setup steps
	•	Ask for 2 to 5 sample pieces the user likes and any they dislike. If none, ask 5 short questions: formality, humor, sentence length, point of view (we, you, I), and three adjectives that describe the brand.
	•	Analyze the samples and write a profile: tone, average sentence length, favorite constructions, vocabulary to prefer, vocabulary to avoid, formatting habits, and example sentences.
	•	Show the profile and let the user correct it. Save it as {brand_voice}.
