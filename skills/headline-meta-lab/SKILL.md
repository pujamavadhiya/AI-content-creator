name: seo-schema-generator
description: Produce title tags, meta descriptions, slugs, image alt text, and valid JSON-LD schema for a finished piece. Use when content is ready to publish or the user asks for meta tags, schema, or structured data.
Steps
	•	Identify page type: Article or BlogPosting, FAQPage, HowTo, Service, Product, LocalBusiness, Organization, Person.
	•	Write 3 title options (50 to 60 characters, keyword near the front) and 3 meta descriptions (140 to 155 characters, benefit plus a reason to click). Recommend one of each.
	•	Write a short slug with the primary keyword.
	•	Write alt text for each image the user lists: describe the image, not keyword stuff.
	•	Generate JSON-LD that matches only what is visible on the page: headline, author, datePublished, dateModified, publisher, mainEntity for FAQs.
	•	Self check: valid JSON, required properties present, no property that isn't on the page, no duplicate schema.
